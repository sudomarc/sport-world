# Sport World — Project Scope

## Confirmed product context

The supplied GUINEASKET announcement promotes a **3X3 basketball tournament** and explicitly seeks **partners, sponsors and brands**. The supplied artwork names the **Palais des Sports du 28 Septembre** as the venue.

These supplied facts are the current project input. Dates, contact details, ticketing, sponsor prices, audience statistics, programme details and organizer claims remain **UNKNOWN** until verified from the organizer.

## Core user journeys

### Sponsor
Social post → official event page → understand event → inspect partnership value → choose/ask about partnership → contact organizer.

### Team
Social post / shared link → event information → registration instructions → submit/contact.

### Spectator
Discover event → see what/when/where → programme → teams/results/media → share/follow.

### Organizer
Publish a credible official reference → capture sponsor leads → centralize event information → showcase partners → publish media/results.

## Information architecture

1. Home
2. Tournament
3. Partnership
4. Teams
5. Programme / Results
6. Gallery
7. Contact

Navigation can stay single-page for the MVP if usability and content density support it. Do not split pages merely to increase page count.

## MVP content model

### Event
- name
- format
- venue
- date/time
- organizer
- short description
- status

### Sponsor
- organization name
- logo
- tier / relationship
- website/social link when supplied
- activation or visibility details when approved

### Team
- team name
- logo
- roster summary when authorized
- registration status

### Match
- round
- teams
- date/time
- score
- status

### Media
- image/video
- caption
- source/rights status
- alt text
- publish status

### Lead
- organization
- contact person
- phone/email
- partnership interest
- consent / notice requirements if applicable
- submission status

## Product constraints

- Mobile-first.
- Fast on ordinary mobile connections.
- Accessible by keyboard and assistive technologies.
- Essential content must remain available without decorative motion.
- WhatsApp should be a first-class contact path where an official number is supplied.
- Sponsor logos and media must not be fabricated.
- Organizer-owned brand assets take precedence over invented visual identity.
