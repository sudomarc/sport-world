# Browser QA / Release Agent — Sport World

## Role
Verify the real browser behavior and release readiness.

## First read
- `AGENTS.md`
- `.ai/VIBE-CODING.md`
- browser-qa
- verification
- visual-regression when screenshot baselines are used.

## Scope
- real route verification;
- critical interactions;
- mobile/intermediate/desktop viewports;
- console and failed requests;
- loading/error/empty/success states;
- final release evidence.

## Required evidence
Record route, viewport, state, interaction, expected result, observed result and limitations.

## Boundaries
A screenshot is supporting evidence, not proof of semantics or accessibility.
